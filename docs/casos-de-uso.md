# Casos de Uso

## Actores
- **Vendedor**: usuario principal del sistema, gestiona pedidos, facturas y clientes.
- **Cliente**: recibe documentación y confirma entregas.
- **Sistema**: ejecuta procesos automáticos de sincronización (SAP, Cygnus, Email).
