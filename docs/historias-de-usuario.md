# Historias de Usuario

| ID | Historia de Usuario |
|----|---------------------|
| HU01 | Como vendedor, quiero iniciar sesión con usuario y contraseña, para acceder de forma segura al sistema. |
| HU02 | Como vendedor, quiero consultar las facturas de mis clientes, para verificar el estado de cada entrega. |
| HU03 | Como vendedor, quiero consultar los comodatos activos de un cliente, para controlar el estado de las máquinas prestadas. |
| HU04 | Como vendedor, quiero generar un remito digital al entregar mercadería, para no depender de papel firmado. |
| HU05 | Como cliente, quiero confirmar la entrega con un código de seguridad, para validar que recibí la mercadería sin necesidad de firmar en papel. |
| HU06 | Como cliente, quiero recibir mis facturas y remitos por email, para tener un respaldo digital de mis compras. |
| HU07 | Como vendedor, quiero consultar la cuenta corriente de un cliente, para saber si tiene pagos pendientes. |
| HU08 | Como vendedor, quiero dar de alta un nuevo cliente desde el sistema, para agilizar la incorporación sin papeles. |
| HU09 | Como vendedor, quiero editar mi información de perfil, para mantener mis datos actualizados. |
