# La Virginia API

API desarrollada para el proyecto de Práctica Profesional del Técnico Superior en Análisis Funcional de Sistemas Informáticos.

El sistema permite gestionar información relacionada con clientes, vendedores, cuentas corrientes, documentos, facturación, rutas de entrega, códigos de seguridad y movimientos de cuentas.

## Tecnologías utilizadas

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Psycopg2
- Uvicorn

## Requisitos

Antes de ejecutar el proyecto es necesario tener instalado:

- Python 3
- PostgreSQL
- Git
